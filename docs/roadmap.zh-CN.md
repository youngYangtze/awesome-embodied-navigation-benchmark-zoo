# Roadmap

[English](roadmap.md) | [简体中文](roadmap.zh-CN.md)

## Milestone 1：建立 Zoo 种子列表

- 添加 15-25 个覆盖不同任务族的代表性 benchmark。
- 在 `data/benchmarks.yml` 中规范化 metadata。
- 添加贡献指南和 issue templates。
- 为每个条目标注 reproducibility status。

## Milestone 2：任务族页面

- 为 ObjectNav、VLN、SocialNav、AudioNav、AerialNav 和 EQA 创建任务页面。
- 添加任务特定的 metric 解释。
- 为新入门者添加“recommended starting benchmark”说明。

## Milestone 3：可复现检查

- 验证高影响力 benchmark 的安装与本地 evaluation 路径。
- 添加逐 benchmark 的 reproduction notes。
- 区分 “paper available”、“code available”、“data available” 与 “leaderboard available”。

## Milestone 4：Foundation-Model Navigation 层

- 添加 VLM、MLLM、LLM、VLA 与 world-model relevance 的比较字段。
- 追踪 zero-shot、fine-tuned 和 RL-fine-tuned evaluation modes。
- 添加 navigation foundation model benchmarks 页面。
