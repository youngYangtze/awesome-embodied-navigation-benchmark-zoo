# Roadmap

[English](roadmap.md) | [简体中文](roadmap.zh-CN.md)

## Milestone 1: Seed the Zoo

- Add 15-25 representative benchmarks across task families.
- Normalize metadata in `data/benchmarks.yml`.
- Add contribution guidelines and issue templates.
- Mark each entry with a reproducibility status.

## Milestone 2: Task-Family Pages

- Create task pages for ObjectNav, VLN, SocialNav, AudioNav, AerialNav, and EQA.
- Add task-specific metric explanations.
- Add "recommended starting benchmark" notes for newcomers.

## Milestone 3: Reproducibility Pass

- Verify installation and local evaluation paths for high-impact benchmarks.
- Add per-benchmark reproduction notes.
- Separate "paper available", "code available", "data available", and "leaderboard available".

## Milestone 4: Foundation-Model Navigation Layer

- Add comparison fields for VLM, MLLM, LLM, VLA, and world-model relevance.
- Track zero-shot, fine-tuned, and RL-fine-tuned evaluation modes.
- Add a page for navigation foundation model benchmarks.
